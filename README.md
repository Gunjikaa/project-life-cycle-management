# Project Life Cycle Management System (PLCMS)

A web-based Project Life Cycle Management System developed as part of a DRDO internship project.

## Overview

PLCMS is intended to digitally manage and track a project's lifecycle from proposal and pre-project activities through reviews, approvals, sanction, execution, monitoring, closure and post-closure.

## Current Workflow

Proposal → Pre-Project → PRC → Technical Evaluation → DMC → AON → IFA → CFA → Sanction → Execution → Monitoring → Closure → Post-Closure

> The exact workflow, roles, authorities and mandatory documents will be validated with the project mentor before being treated as an official process.
